Xen0UI Engine Documentation

A springy, highly-animated user interface system built for adaptive Light and Dark custom execution layouts.

1. Library Bootloading Initialization

Load the universal workspace layout library from memory via an environment loadstring block before instantiating custom components.

local Xen0UI = loadstring(game:HttpGet("https://githubusercontent.com"))()

2. Instantiating a Window Instance (CreateWindow)

Generates the main graphic window frame after launching the Xen0 UI fluid splash screen zoom layout sequence.

Parameter Type Default Description
Name string "Xen0 UI Engine" The core visual text title rendered on top of the structural hub.
Theme string "Light" Switches visual arrays. Accepts "Light" or "Dark" color styles.
LoadingTitle string "Xen0 UI"
